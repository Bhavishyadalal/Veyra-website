Veyra

Made by Bhavishya Dalal. The app repository is Bhavishyadalal/Veyra. The Android app is a modified GPL-3.0 project; upstream copyright, attribution and existing third-party notices are retained in its source.

Website and illustrations

This showcase uses React, Motion and Vite. Its Nocturne, Bloom and Orbit covers are original illustrative artwork for this website preview, not commercial album covers. Their track names and credits are fictional and do not represent an included music catalogue.

Original visual world

The liquid-glass gateway, horizon lens, crystal orchid and floating monolith were generated for this website using OpenAI image generation and encoded as local WebP assets. The interactive phone is an illustrative web reconstruction inspired by Veyra, not a screenshot or a running Android app.

The glass waveform

The website uses the actual default black-and-white glass waveform artwork from the supplied Veyra Android project. It is presented as the project’s brand asset, not as a third-party music-service logo.

Manrope

Body and interface text use a local Latin subset of Manrope. The original typeface is distributed under the SIL Open Font License. Read the included Manrope licence.

Anton

The bold display headings use Anton, supplied by Google Fonts under the SIL Open Font License.

Syne and Bodoni Moda

Display headings use Syne and italic editorial accents use Bodoni Moda. Both are locally served variable fonts from the official Google Fonts repository, under their SIL Open Font Licenses: Syne OFL and Bodoni Moda OFL.

Super Malibu

The “Veyra” wordmark uses a local subset of the Super Malibu Regular file supplied by the project owner. The owner confirmed permission for embedding and public source redistribution. No upstream licence/readme accompanied the font; the source package records that provenance and does not claim that the font is covered by Manrope’s OFL.

Tools and component licenses

The website uses React, React DOM, Motion and Lucide in the browser, with Vite and Tailwind for local builds. Playwright and axe-core support browser checks. FluxLines, SpecularButton, ScrollStack, SplitText, GlassSurface, GlareHover, DecryptedText and ShinyText are included from the official React Bits source under its MIT + Commons Clause terms. The source archive retains the complete notice.

SplitText is the TypeScript/Tailwind variant and uses GSAP, ScrollTrigger, GSAP SplitText and @gsap/react under the GSAP Standard no-charge license. These third-party terms are separate from the original website code’s MIT license.

The FrequencyReel interaction is original website code. The requested React Bits Pro Starter vertical-reel component requires a buyer’s licensed registry and is not included or represented as installed. No paid source, account configuration or license key is bundled.
